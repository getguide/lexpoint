# Lexpoint.io - Canada's Leading Legal Technology Platform

## 🚀 Overview

Lexpoint.io is Canada's premier legal technology platform, revolutionizing how legal services are accessed, managed, and delivered across the country. Our platform offers innovative solutions for legal directory, immigration compliance, and immigration coaching services.

## 🎯 Mission

We're on a mission to transform the traditional legal industry in Canada through innovative technology solutions that make legal services more accessible, efficient, and user-friendly.

## 🛠️ Products

### 📋 Canada Legal Directory
The most comprehensive directory of Canadian legal professionals, making it easy to find the right lawyer for your needs.

### 🏢 ImmiCare
Canada's first employer immigration compliance system, ensuring your business stays compliant with immigration regulations.

### 👨‍💼 ImmiCoach
The TurboTax for Immigration - simplifying the complex immigration process with step-by-step guidance.

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Local development server (optional)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/lexpoint.io.git
   cd lexpoint.io
   ```

2. Open `index.html` in your browser or serve locally:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

3. Visit `http://localhost:8000` in your browser

## 🚀 Deployment

### GitHub Pages
1. Push your code to GitHub
2. Go to repository Settings > Pages
3. Select source branch (usually `main`)
4. Your site will be available at `https://username.github.io/repository-name`

### Custom Domain
1. Add your domain to GitHub Pages settings
2. Update DNS records
3. Update meta tags in `index.html` with your domain
