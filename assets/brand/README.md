# Lexpoint Brand Assets

Please upload your brand assets to the appropriate folders:

## 📁 Folder Structure

### `/logos/`
- Primary logo (PNG, SVG preferred)
- Logo variations (horizontal, vertical, icon-only)
- Favicon files
- Any logo usage guidelines

### `/colors/`
- Color palette files (Adobe Color, Sketch, Figma exports)
- Brand color specifications
- Any color usage guidelines

### `/fonts/`
- Custom font files (if any)
- Typography specifications
- Font pairing guidelines

### `/images/`
- Brand photography
- Stock images for the website
- Icons and graphics
- Any visual style guides

## 🎨 Brand Guidelines
Once you upload your assets, please share:
- Brand personality/tone of voice
- Target audience
- Key value propositions
- Any specific design preferences

This will help create the most impactful landing page for Lexpoint.io!
