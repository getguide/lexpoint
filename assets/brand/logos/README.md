# Logo Variations

## 📁 Logo Structure

### `/accent/`
- Colored/Accent version of the logo
- Use for primary branding and main website sections
- Best for light backgrounds

### `/black-and-white/`
- Black and white version
- Use for high contrast situations
- Good for dark backgrounds or when color isn't available

### `/white-only/`
- White version of the logo
- Use for dark backgrounds
- Perfect for footer, dark sections, or overlay situations

## 🎯 Usage Guidelines
- **Accent**: Primary logo for most website sections
- **Black & White**: High contrast areas, print materials
- **White**: Dark backgrounds, overlays, footer

Please upload your logo files to the appropriate folders based on their color variations.
